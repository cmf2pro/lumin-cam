# LUMIN CAM — Product Vision

## Vision

Build a practical, approachable 3-axis CAM system for CNC/VMC programmers that turns CAD geometry into verified machining programs through a clear, guided workflow.

## Mission

Reduce the learning curve of CAM software without hiding the controls that experienced machinists need.

## Product Principles

1. **Machinist first** — workflows should match real CNC/VMC practice.
2. **Clear before clever** — every parameter should have a visible machining purpose.
3. **Verify before export** — simulation and validation are core product features, not optional extras.
4. **Modular engineering** — geometry, CAM, simulation, collision, and posting remain separable.
5. **Progressive complexity** — Beginner Mode first, Professional Mode when needed.
6. **Deterministic core** — AI may assist planning, but validated CAM algorithms produce toolpaths and G-code.
7. **Real-world controller awareness** — post processors and machine settings matter.

## Long-Term Goal

LUMIN CAM should evolve from a focused 3-axis CAM application into a broader manufacturing platform with feature recognition, intelligent process planning, machine libraries, advanced verification, and eventually multi-axis foundations.

## What LUMIN CAM Is Not

LUMIN CAM is not initially intended to be a full CAD replacement or an immediate clone of every capability found in mature commercial CAM platforms. The first objective is to make a smaller set of machining workflows reliable, understandable, and testable.
